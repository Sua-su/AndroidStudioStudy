# 구현 이력 (Implementation Log)

## 개요
TMDB API와 Room을 결합한 영화 리뷰 관리 앱 'TMRB Android'의 개발 과정을 기록한다.

## 주요 결정 사항 및 트레이드오프

### 1. Jetpack Compose 사용
- **결정**: XML 대신 Compose를 사용하여 UI를 구축.
- **이유**: 최신 Android 개발 트렌드이며, 선언형 UI를 통해 코드 양을 줄이고 상태 관리를 직관적으로 수행할 수 있음.

### 2. Room을 통한 로컬 저장소 활용
- **결정**: 리뷰 및 사용자 데이터를 로컬 DB(Room)에 저장.
- **이유**: F-04(영속화) 요구사항을 충족하며, 오프라인 상태에서도 사용자가 작성한 리뷰를 조회할 수 있게 하기 위함.

### 3. MVVM 아키텍처 및 Hilt 사용
- **결정**: ViewModel과 Repository 패턴을 적용하고 Hilt를 통해 의존성을 주입.
- **이유**: 코드의 가독성, 유지보수성, 테스트 용이성을 높이기 위함.
