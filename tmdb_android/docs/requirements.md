# 요구사항 명세서 (Requirements Specification)

## 1. 프로젝트 개요
- **프로젝트명**: TMRB Android (The Movie Review Board)
- **개요**: TMDB API를 활용하여 영화 정보를 조회하고, 사용자가 영화에 대한 리뷰를 작성 및 관리할 수 있는 Android Native 앱.
- **주요 기술 스택**: Kotlin, Jetpack Compose, MVVM, Room, Retrofit, Hilt, Navigation.

## 2. 사용자 시나리오
1. 사용자는 앱을 실행하면 현재 인기 있는 영화 목록을 확인할 수 있다.
2. 사용자는 특정 영화 제목으로 영화를 검색할 수 있다.
3. 영화 목록에서 영화를 클릭하면 해당 영화의 상세 정보(줄거리, 평점, 개봉일 등)를 볼 수 있다.
4. 상세 화면에서 사용자는 해당 영화에 대한 리뷰를 작성할 수 있다.
5. 사용자는 본인이 작성한 리뷰 목록을 별도의 화면에서 확인하고, 수정하거나 삭제할 수 있다.

## 3. 기능 요구사항

### F-01: 리뷰 CRUD (핵심 엔티티)
- **생성**: 영화 상세 화면에서 별점과 코멘트를 입력하여 리뷰를 저장한다.
- **조회**: 영화 상세 화면 또는 '내 리뷰' 화면에서 저장된 리뷰를 확인한다.
- **수정**: 작성한 리뷰의 별점이나 내용을 수정할 수 있다.
- **삭제**: 작성한 리뷰를 삭제할 수 있다.

### F-02: 주요 화면 구성 (최소 3개 이상)
- **홈 화면**: 인기 영화 / 상영 중인 영화 목록 표시.
- **상세 화면**: 영화 상세 정보 및 리뷰 작성/목록 표시.
- **검색 화면**: 영화 제목 검색 결과 표시.
- **내 리뷰 화면**: 사용자가 작성한 모든 리뷰 목록 관리.

### F-03: 입력 검증 및 예외 처리
- 리뷰 작성 시 내용이 비어있거나 별점이 선택되지 않은 경우 안내 메시지 표시.
- 네트워크 연결 실패 시 오프라인 상태 안내 및 로컬 데이터(리뷰) 접근 지원.

### F-04: 데이터 영속화
- **Room**: 사용자의 리뷰 데이터 및 커뮤니티 게시글 정보를 로컬 DB에 저장.
- **Retrofit**: TMDB API로부터 실시간 영화 데이터 로드.

### F-05: 커뮤니티 게시판
- 사용자는 자유롭게 글을 작성하고 목록을 확인할 수 있다.
- 프로필 설정에서 닉네임을 설정한 경우 작성자로 표시되며, 설정하지 않은 경우 '익명'으로 표시된다.
- 본인이 작성한 글을 삭제할 수 있다.

### F-06: 프로필 설정
- 앱 내에서 사용할 닉네임을 설정하거나 변경할 수 있다.

### F-07: 실시간 트렌드 수집 (웹 크롤링)
- Jsoup 라이브러리를 사용하여 KOBIS(영화진흥위원회) 등의 외부 사이트에서 실시간 박스오피스 순위를 수집하여 표시한다.
- API 외부의 데이터를 가공하여 사용자에게 유용한 정보를 제공한다.

### F-08: 게이미피케이션 (업적 및 뱃지 시스템)
- 사용자의 활동(리뷰 작성 등)에 따라 업적을 달성하고 뱃지를 부여한다.
- 프로필 화면에서 획득한 뱃지 목록을 시각적으로 확인할 수 있다.
- **성능**: 이미지 로딩 라이브러리(Coil)를 사용하여 매끄러운 스크롤 제공.
- **디자인**: Material 3 가이드라인을 준수하여 모던하고 직관적인 UI 제공.
- **오프라인 지원**: 이미 로드된 영화 정보나 사용자의 리뷰는 네트워크 연결 없이도 조회 가능해야 함.
